# WealthPilot AI Frontend — V32

Deployable static frontend shell for the WealthPilot AI product.
Includes responsive dashboard, portfolio tabs, holdings, performance, allocation, goals, AI Advisor UI, language selector, currency selector with portfolio recalculation, and quick-action interactions.

This build is intentionally frontend-only. Supabase Auth/database wiring remains a separate integration gate and must not be represented as connected until tested against the production project.
